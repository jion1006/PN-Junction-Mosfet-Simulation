# PN-Junction-Mosfet-Simulation

---
## 프로젝트 개요
반도체 도핑 시뮬레이션 atlas를 사용하여 도핑농도, 온도 등 영향을 줄 수 있는 요소에 따른 전류 전압을 시뮬레이션하고 이론과 비교하여 차이의 원인을 분석하였습니다.
